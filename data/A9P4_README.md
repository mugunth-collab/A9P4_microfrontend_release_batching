# A9P4 - A Scalable Micro-Frontend Architecture for Modular Native Feature Delivery in Large-Scale Mobile Engineering Environments

**Track:** Track 6  
**Application:** Modular blockchain wallet and energy-trading mobile app

This dataset is synthetic, generated by gen_author9.py with seed 2120. It must be described as synthetic in any publication.

## Simulated scenario

A mobile blockchain wallet with a peer-to-peer energy-trading marketplace (wallet core, token swap, staking, meter link, KYC, carbon credits, ...) is migrated from a monolith via a modular monolith to a micro-frontend architecture during 2025-2026. Each row is a merged change with module, architecture, coupling, team coordination, security and delivery metrics, and post-release outcome.

## How it was generated

Micro-frontend adoption follows a logistic ramp over time. Micro-frontends lower cross-module coupling, teams involved and build times, and raise contract-test adoption. Lead time = review + build + coordination delay x (1 - contract-test benefit) + architecture-dependent release-train wait (log-normal). Incidents (~8%) come from a noisy latent of size, coupling, shared deps, ABI changes without contracts, coverage, flags and security-critical modules.

Realism noise common to all numeric signals: ~5% multiplicative Gaussian measurement noise, 1-3% missing values in a few columns (empty cells), and ~0.5-1% injected outliers (listed per table below). Targets were computed from the noise-free latent signals, so the observed features are imperfect proxies.

## Target / label column(s)

## Suggested experiments

1. Interrupted time-series / difference-in-differences on lead time before vs after each module adopts micro-frontends.
2. Lead time prediction (log R^2, MAE) with architecture and coupling features; SHAP to quantify architecture effect.
3. Incident prediction (PR-AUC, F1); compare risk by architecture at matched change size (propensity matching).
4. Team autonomy metric: teams_involved and cross-module touches per architecture; statistical tests (Mann-Whitney).
